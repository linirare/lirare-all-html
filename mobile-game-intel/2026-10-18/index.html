01｜阅文公布《群星漫卡》：多国漫 IP 进入电子集换卡牌赛道

2026 阅文创作大会披露，《群星漫卡》由阅文联合蹊迹游戏开发，集结《斗罗大陆》《吞噬星空》《狐妖小红娘》等 IP。项目已于9月底完成首次线上保密测试，预计2027年推出，并计划近期公布公开测试信息。官方定位为多 IP 电子集换式卡牌手游。

编辑研判｜IP 联动正在从单纯皮肤授权走向卡牌收藏、构筑和跨角色竞技。值得持续追踪的是“跨 IP 卡牌的稀有度设计、交换生态、竞技平衡”，而不是简单照搬 IP 数量。

02｜《失落城堡2》手游定档10月22日公测

雷霆游戏旗下《失落城堡2》移动版在 TapTap 与中国区 App Store 显示预计于10月22日推出，安卓与 iOS 双平台。产品延续 Roguelike 横版动作冒险，重点扩展局内随机宝物构筑、联机合作与战斗表现。该日期属于未来已公布档期，尚非已上线的事实。

建议｜10月22日起重点记录首日预约转下载、畅销与免费榜位次、手机端操作适配，以及“动作爽感+局内构筑”能否转化为长留。

03｜腾讯守住榜首：37家中国手游厂商全球收入预估20亿美元

Sensor Tower 公布2026年9月中国发行商收入榜：37家中国厂商进入全球手游发行商 TOP100，合计收入预估20亿美元，占全球 TOP100 收入的41.6%。头部七强座次不变，哔哩哔哩发行商收入环比增长36%，排名提升7位。

04｜全球手游买量素材回升至362万组，轻度玩法仍主导投放

DataEye-ADX 海外版报告显示，2026年9月全球手游在投素材达362万组，较8月增长约4.4%；在投产品约6万款，较8月增长约20%。中国出海手游在投素材约53.7万组，产品3022款。轻度拼图、益智、消除仍位列头部；《疯狂水世界》在韩国扩张投放。

编辑部建议：接下来应该做什么

优先级 A · 拆买量创意

挑选《疯狂水世界》《Block Blast!》等产品的热门广告，拆出前3秒钩子、失败反馈与胜利兑现，再做可运行的低成本验证素材。

优先级 B · 看长线付费

以《阴阳师》《金铲铲之战》为样本，研究限定内容、活动节奏与老用户召回，不把周年庆收入峰值误读为常态。

优先级 C · 关注轻量 IP+构筑

跟踪《群星漫卡》公开测试后，重点观察收藏动机和策略竞技是否可以兼得。
