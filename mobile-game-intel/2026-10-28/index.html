腾讯魔方《洛克王国：世界》开启海外封闭测试

10月27日 · 封闭测试开启

腾讯魔方工作室旗下《洛克王国：世界》于10月27日开启面向海外玩家的邀请制封闭测试。制作团队表示，国际版将以开放世界探索、回合制宠物战斗及跨平台存档为核心，商业化重点放在外观和通行证，不以付费抽取宠物形成PvP战力优势。全球正式上线目标为2027年年中，仍以官方后续公布为准。

研发 / 发行启示

值得拆解“公平竞技＋宠物收集＋外观付费”的IAP模型。重点观察付费转化是否足以覆盖长线内容成本，以及海外本地化如何处理宠物名称、UI与新手引导。

核验与口径：30天测试、2027年年中上线均为制作团队计划；原报道提到的中国首周玩家规模属于采访转述，不作为本期审计数据。

02公司动态 / 运营风险长线运营 / 风险

腾讯天美研发《宝可梦大集结》宣布2027年3月23日停服

10月26日官方公告 · 10月27日报道

《宝可梦大集结》官方宣布，移动端与Nintendo Switch版将于2027年3月23日00:00 UTC停止服务。游戏内付费宝石销售、会员新购与自动续费已于10月27日停止。该作于2021年推出，由腾讯天美工作室群开发；官方未披露停服的具体经营原因。

研发 / 发行启示

强IP和高下载量并不等于可持续运营。新项目应将D30/D90留存、付费用户留存、赛事与内容维护成本一起纳入生命周期评估，并为停服时的玩家权益处理预留机制。

核验与口径：停服时间与支付停止日期来自官方公告。媒体披露的AppMagic收入估算存在不同口径，本期不采用未经统一核验的累计收入数字。

04AI研发 / 世界模型AI / 原型验证

Google DeepMind发布Genie 4：实时交互世界加入原生音频与文字改场景

10月27日 · 官方发布

Google DeepMind于10月27日公布Genie 4研究预览。新模型支持在交互过程中通过文字修改天气、镜头和角色，并同步生成环境声、音乐及对话；Gemini模型协助规划场景连续性。当前仅向受邀测试者开放，后续计划扩大到Project Genie和部分API合作伙伴。

研发 / 发行启示

对手游团队，短期价值在玩法概念可视化、场景预演与交互原型，而非替代Unity/Cocos正式工程。建议重点验证角色状态一致性、碰撞逻辑、可导出性和每次迭代成本。

核验与口径：能力与开放计划来自Google官方；官方明确承认长时一致性、物体恒存、空间精度和文字渲染仍有限制。

05发行买量 / IAA研究IAA / 待独立核验

《Block Blast!》逆向拆解视频走红：动态难度与广告投放说法尚未证实

10月27日 · 行业报道

Mobilegamer.biz报道，内容创作者Ayo Omolewa声称逆向研究《Block Blast!》《Candy Crush Saga》《Subway Surfers》，并在短视频中讨论个性化广告、难度动态调整与付费推荐机制。相关视频获得较高传播，但报道主要转述创作者观点，未提供足以独立验证各款游戏实际线上算法的证据。

研发 / 发行启示

值得把“难度调节—失败节点—激励广告触发”作为IAA实验议题，但不能据此认定竞品存在操纵机制。可用公开可重复的关卡样本、用户分组和埋点验证自己的难度曲线，避免牺牲公平感换取短期广告展示。

核验与口径：创作者声称不等于被证实的产品机制；不引用其对游戏公司的指控作为事实，不提供未经验证的广告收益、eCPM或ROAS数字。

IP热度不能代替长期留存与商业化验证

《宝可梦大集结》宣布停服，与《洛克王国：世界》海外测试同日出现，提醒研发团队：上线热度、IP认知和累计下载都不足以证明生命周期健康。建议在项目软启动阶段设定D7/D30、付费留存、内容产能、获客成本和LTV的统一评估表，并每月复盘付费公平感与运营成本；避免先扩量、后补经营模型。
