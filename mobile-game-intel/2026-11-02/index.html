10月29日移动版上线 · 10月30日报道

独立开发者AP Thomson与发行商Fellow Traveller的《Titanium Court》于10月29日扩展至iOS、Android等平台。游戏把三消地形操作、资源收集、单位部署、自动战斗和Roguelite成长放进同一战场，10月30日被PocketGamer.biz列入当周值得关注的手游新品。PC版本此前已于4月推出。

04AI研发 / H5

Playgama发布AI Game Index：用真实试玩时长比较AI制作的网页游戏

10月30日报道 · 11月1日平台快照

网页游戏分发平台Playgama推出AI Game Index，按开发者所填AI工具、玩家游玩时长及点赞表现进行统计。11月1日官方页面显示样本已超过6100款游戏、160万次启动；Claude Code占平台收录游戏约50%，Codex约18%。在符合样本门槛的作品中，OpenCode组的游戏时长中位数约4分42秒。

对国内研发 / 发行的启示

这类数据比单纯比较代码生成速度更接近产品结果。建议对同一H5玩法用不同AI工具产出原型，统一素材与关卡条件，实测首局完成率、平均局时和D1留存，而非把平台相关性当作模型因果能力。

统计口径与限制：Playgama AI Sandbox平台内部样本；工具/模型由开发者自行填报且未核验，游戏质量、题材、作者经验存在选择偏差。页面数据截至11月1日，不代表全行业。

05发行 / IAP变现

《Gods and Demons》披露跨商店软启动：封测D1留存41.93%

2026年10月30日 · 发行访谈

Moye Interactive Entertainment在10月30日赞助访谈中介绍放置卡牌《Gods and Demons》的多商店发行策略，覆盖Google Play、苹果App Store及华为AppGallery。公司称早期封测前两天有1421名新玩家创建角色，D1留存为41.93%，高于其设定的35%目标；同时通过分阶段测试调整月卡、成长基金和通行证。

对国内研发 / 发行的启示

国内IAP团队可借鉴「先软启动验证留存—分商店适配SDK—按地区付费习惯调整礼包」的路径。建议特别检查安卓中低端机发热、渠道归因和跨商店账号体系，避免用一个小样本留存率直接支持规模化买量。

统计口径与限制：数据来自厂商在PocketGamer.biz赞助内容中的自述，非独立审计；1421为前两天创建角色人数，D1留存41.93%并非长期留存，未披露获客成本和ROAS。
