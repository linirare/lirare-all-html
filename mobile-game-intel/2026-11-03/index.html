02AI内容 / 发行上市公司 / AI / 变现

手游发行商Gamehaus拟控股AI漫剧平台，交易合计2660万美元

2026-11-02 公告

纳斯达克上市手游发行商Gamehaus宣布，拟以1960万美元股票对价收购Techforge部分股份，并另投入700万美元现金增资；交易完成后预计持股约56%。Techforge持有AI短剧平台Anamana。Gamehaus希望将现有游戏买量、数据分析和变现经验延伸至AI内容生产与分发。

研发 / 发行启示

重点不是直接把漫剧搬进游戏，而是验证游戏发行的投放优化能力能否复用到AI连续剧；国内IAP/IAA团队可低成本测试“剧情广告—落地页—互动内容”链路，并分别核算素材成本与回收。

口径 / 核验：2660万美元=1960万美元股份收购对价+700万美元现金增资；不是全部现金支出。56%为交割后预计持股，交易尚未完成。

05创新玩法 / IAP创新玩法 / 移动移植

《编程农场》移动版上线：写代码驱动农场，免费试玩后买断

2026-11-02 欧美上线报道｜日本11-03报道

《The Farmer Was Replaced》（《编程农场》）按计划于11月2日推出iOS/Android移动版，玩家用类似Python的代码指挥无人机种植、收获和自动化生产。移动版加入触屏专用代码键盘，并包含采矿扩展内容。美国App Store标注免费下载安装、完整版一次性解锁8.99美元，无广告和订阅。

研发 / 发行启示

这款产品值得拆解“规则可编程—效率提升—资源解锁”的成长循环；对国内小游戏可抽象为轻量指令拼接或流程卡片，而非要求普通玩家直接敲代码。买断制与国内IAA受众的适配性仍需验证。

口径 / 核验：11月2日为欧美报道及开发者原定档期，日本媒体按当地时区报道11月3日；8.99美元为美国App Store标价，非国区价格，实际商店可用性因地区而异。

今日最值得关注的机会

AI剧情素材 × 手游买量数据闭环

Gamehaus的拟议交易说明，手游发行商开始把AI内容生产、广告获客和变现分析放进同一业务链。建议国内IAA/IAP团队先做一轮低成本验证：针对同一款产品制作3组不同叙事结构的AI剧情短素材，保持定向、预算和落地页一致，比较CTR、CVR、D1留存、付费率与7日回收。不要把厂商宣称的“生产成本下降97%”直接当作可复制的实际节省，也不要在没有数据时扩大投放。
