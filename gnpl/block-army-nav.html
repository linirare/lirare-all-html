01核心玩法 · 拼块布阵与自动战斗

4×5 棋盘拖放四色兵块（粉=攻击 / 绿=生命 / 蓝=护甲 / 黄=攻速）拼阵型 → 出兵自动对战 → 双方城墙对攻，先拆对面城墙者胜。

1.1 拼块与棋盘

  • 棋盘：4 列 × 5 行 = 20 格，任意空位落块（非固定堆叠）
  • 拼块槽：4 个槽位，开局随机生成，放置后自动补新块
  • 拼块构成：形状（12 种，2-6 格：双子横条 / 左角块 / 三连条 / 方阵块 / 战术L / 火力T / 闪电Z / 右角块 / 巨型L / 巨型J / 贯穿长条 / 重装方阵）+ 颜色（四属性之一）随机组合，单色不可旋转
  • 操作：拖拽进棋盘（绿/红合法性预览）→ 可再拖动调整 → 可收回
  • 费用：放置免费；点击「出战」清空棋盘出兵，扣 10 金币
  • 刷新：右上角「换一波」按钮，看广告刷新当前拼块（每日上限 20 次）
  • 撞墙返还：我方兵撞敌方城墙返还一半出战费（+5 金币）
四色属性规则（当前实现）

每放入一个彩色小格，只给对应属性 +1；形状只决定占格数与摆放空间，不携带隐藏属性或等级。四项属性：

粉 ■ 攻击 · 蓝 ■ 护甲 · 黄 ■ 攻速 · 绿 ■ 生命

上阵方块数倍率：摆 1 块 ×1、2 块 ×2、3 块 ×3、4 块及以上 ×4（只数上阵方块总数，与是否相连无关）。拼得多而整则越强。

属性账本：战斗面板同时显示「色格属性值」与「实际战斗值」，并标注当前主色与并列判定。

1.2 出兵判定：颜色决定兵种

  • 点击「出战」清空棋盘出兵 + 彩色纸屑特效，扣 10 金币
  • 最多颜色决定本次出战兵种线：粉=剑士系、蓝=盾卫系、黄=弓手系、绿=灵医系
  • 数量并列：以最后一次成功落下的方块颜色决定（存档记录该项）
  • 出战兵种由棋盘主色自动决定，不手选；星级只解锁技能，不改变基础属性

数值换算（客户端/服务端同源）：生命 / 护甲 / 攻击 =（天赋基础 5 + 对应色格数）× 上阵方块数倍率；攻速 =（0.25 + 黄格 × 0.1）× 倍率，最高 3 次/秒。兵种差异体现在攻击距离 / 目标逻辑 / 星级技能。

1.3 自动战斗

  • 出兵后自动战斗，按帧推进
  • 移动：友军冲向最近敌人，敌军冲向玩家城墙；灵医特殊走位（拉向受伤队友）
  • 近战：普攻 + 暴击 + 克制加成 + 光环，可顺劈相邻目标
  • 远程：投射物飞行、护甲减伤、破甲状态结算；弓手多箭齐发
  • 治疗：灵医给最受伤友军连线治疗；无队友可治疗时转攻击吸血
  • 城墙攻防：单位到达城墙造成伤害；普通波可一路拆到 0，妖王存活时敌方城墙锁血；妖王破城直接判负
  • 被动金币：每 5 秒 +1；每击杀 2 名敌人 +1；我方兵撞敌方墙返还一半出战费（+5 金币）

1.7 胜负与结算

  • 我方城墙与敌方城墙血量逐关配置（随章节递增：我方 200~400，敌方 380~3200），初始金币 40
  • 敌方城墙 0 → 胜利；我方城墙 0 → 失败；妖王破城直接判负（妖王到达我方城墙）
  • 普通波可拆墙到 0；妖王存活时敌方城墙锁血，击杀妖王获胜
  • 结算界面：下一关 / 看广告复活（回 40% 城墙 + 清空敌方非首领单位 + 重置敌军攻势）/ 看广告翻倍奖励（双倍金币，每日 1 次）/ 战败安慰奖励 / 返回首页
  • 评价 S/A/B/C/D：按我方城墙剩余血量比例（≥75% S、≥50% A、≥25% B、其余 C，战败 D）
  • 胜利宝箱：金币（首通区间随机 / 重复按每日胜次逐关表）+ 概率碎片 + 宝物掉落（见「数值配表」）
